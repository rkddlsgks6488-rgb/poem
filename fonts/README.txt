[순우리말 시 공방 — 로컬 폰트 폴더 안내]

이 폴더(./fonts/)에 다운로드하신 폰트 파일을 아래 이름으로 넣으시면
index.html 상단의 @font-face 슬롯(폰트 1 ~ 폰트 4)과 자동 연결됩니다.

- font1.ttf 또는 font1.woff2  -> [폰트 1] 슬롯
- font2.ttf 또는 font2.woff2  -> [폰트 2] 슬롯
- font3.ttf 또는 font3.woff2  -> [폰트 3] 슬롯
- font4.ttf 또는 font4.woff2  -> [폰트 4] 슬롯

※ 또한 웹 화면의 [+ 내 컴퓨터에서 폰트 파일(.ttf, .otf, .woff) 불러오기] 버튼을 클릭하면
별도의 코드 수정 없이도 즉시 원하는 폰트 파일을 선택해 시화에 적용하실 수 있습니다.
